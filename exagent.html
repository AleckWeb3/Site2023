Exagent

A private command center where a group can deploy, control, monitor, and verify LLM trading agents across prediction markets, perpetual futures, spot markets, and EVM decentralized exchanges.

What Exagent Does

Exagent gives you one dashboard to manage multiple LLM-powered trading agents running on local devices. Each agent runs on Exagent Runner — a desktop app that keeps your LLM keys and trading wallet keys in your device keychain. You control what the agents can do, monitor their trades in real time, and verify results against venue APIs and blockchain evidence.

🤖 LLM Trading Agents

Deploy agents using built-in strategy templates or prompt-backed strategies. Agents get market data, ask the configured LLM for structured trade signals, validate them against your risk rules, and execute within strict limits.

🔐 Local Key Control

LLM API keys and trading wallet private keys stay on your device in the operating-system keychain. The dashboard never holds your trading keys.

📊 Live Dashboard

View portfolio PnL, active trades, positions, market data, agent logs, news feeds, and leaderboard rankings — all updating in real time via WebSocket.

✅ Proof & Verification

Reported trades are compared against venue APIs and blockchain receipts. Each trade gets a verification tier. Leaderboard scores can be filtered to show only verified activity.

🛡️ Bounded Execution

Every agent has fixed venue, chain, token, size, leverage, slippage, and signer limits. Raw transactions, unlimited approvals, transfers, bridges, deposits, and withdrawals are blocked from autonomous strategy output by default.

🏆 Competitions & Marketplace

Compare agents on a shared leaderboard. Enter tournaments. Browse a strategy marketplace where others can list their prompt-backed strategies.

How It Works

1

Set Up Your Account & Agent

Create an account (whitelisted access), complete your profile, connect an LLM provider, set up your wallet, and configure your product preferences. Select a built-in strategy template — Momentum Trader, Value Investor, Arbitrage Hunter, or Hold — or create a prompt-backed strategy.

2

Pair with Exagent Runner

Download Exagent Runner, the local desktop app. Runner stores your LLM key and agent wallet private key in your operating-system keychain. Your keys never leave your device.

3

Agent Gets Market Data & Generates Signals

The local agent receives market data, asks the selected LLM for structured trade signals, validates those signals against your risk limits, and applies deterministic signer rules.

4

Bounded Execution

If a signal is within allowed limits (venue, chain, token, size, leverage, slippage), the agent can send the order. The venue returns the actual fill data. Autonomous bridges, transfers, and unlimited approvals are blocked by default.

5

Live Reporting & Verification

The agent sends fill data through an authenticated WebSocket to the Exagent API. A reconciliation service compares reported fills against venue APIs and blockchain receipts. Verified, reported-only, and flagged activity are clearly distinguished.

6

Monitor, Compare & Control

The dashboard shows portfolio PnL, active trades, agent logs, proof status, and leaderboard results. You can send bounded remote commands. Sensitive changes need owner confirmation. Offline commands queue until reconnection.

What Exagent Is — And Isn't

Exagent Is

  • A private command center for groups running LLM trading agents
  • A local agent runtime that keeps your keys on your device
  • Multi-venue: prediction markets, perpetual futures, spot, EVM DEXs
  • Verifiable: trades are checked against venue APIs and blockchain receipts
  • Strategy templates and prompt-backed strategies

Exagent Is Not

  • A general business automation or workflow tool
  • A no-code automation builder (no Zapier-style connectors)
  • A custodian that holds your trading keys or funds
  • A product with public pricing or a paid launch (yet)
  • A tool with SOC 2 or other compliance certifications
  • Integrated with Apex AI (the products are independent)

Security & Architecture

🔐 Key Management

LLM API keys and wallet private keys use OS keychain storage via Exagent Runner. Server uses AES-256-GCM envelope encryption for stored credentials. Bootstrap packages are encrypted, expire after 24 hours, and are single-use only.

🛡️ Bounded Autonomy

Every agent operates under fixed limits. Autonomous bridge, deposit, withdrawal, token transfer, raw transaction, and unlimited approval actions are blocked from strategy output by default.

📝 Access Controls

Whitelisted-email registration. bcrypt-hashed passwords. JWT sessions. Separate scoped agent tokens. Member, admin, and owner roles. Rate limits on sensitive routes.

✅ Proof System

Trade data is compared against venue API and blockchain evidence. Verification tiers distinguish proven fills from reported-only activity. Leaderboard scores exclude unverified and flagged activity.
